# RecipeFinder

RecipeFinder is a Spring Boot application designed to help users find recipes based on available ingredients. It uses Elasticsearch for efficient searching and MySQL for data storage.

## Features

* **Recipe Search**: Find recipes by "must-have" and "should-have" ingredients.
* **Elasticsearch Integration**: Utilizes Elasticsearch for fast recipe search.
* **RESTful API**: Provides an endpoint for recipe searching.
* **Dockerised**: Easily set up with Docker Compose, including MySQL, Elasticsearch, and Kibana.

## Technologies

* Spring Boot
* Spring Data Elasticsearch
* MySQL
* Elasticsearch
* Kibana
* Gradle
* Java 21
